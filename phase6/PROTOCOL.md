# Phase VI frozen screening protocol

Authority: current repository, the two Phase V final reports, and the supplied Phase VI prompt. No prior conversations were consulted. This is the raw WANDS/BGE track; labeled PI-FT weights, serializers, training pairs and fitting definitions are excluded.

Preserve the 42,994-item catalog in source order; the Phase V 72/24/384 query split (54/17/308 Exact-eligible queries); all 546 existing raw-track Exact/Irrelevant training triples; unchanged frozen BGE query, native-atom, and fixed non-attribute caches. Verify source text hashes, pinned model revision, shapes and normalization. Preserve each atom and every duplicate occurrence. Parse field identity from the trimmed native key before the first colon, without semantic rewriting; malformed/empty keys map to UNK. Vocabulary uses only products appearing in training triples, sorted lexicographically, with an explicit trainable UNK at ID 0. Unseen catalog keys map to UNK. Product identities may overlap splits, as in the inherited query split.

S1: content projection 768->128, one four-head self-attention block, residual and layer normalization, 128->256->128 GELU feed-forward; one learned seed with multihead attention pooling, residual/norm/feed-forward; output projection 128->768. No positional encodings, no dropout. S2 differs only by adding a learned 128-dimensional field-ID embedding after content projection. S3: projected content concatenated with cos/sin of a trainable field-specific angle, per-atom 130->128->128 GELU MLP, masked mean, 128->128->768 output MLP. Angles initialize evenly across the sorted training vocabulary including UNK. S4 is the inexpensive matched infrastructure control: replace S3's circular identity with an ordinary learned 128-dimensional field identity, retain per-atom MLP, masked mean and output MLP. S3-fixed is omitted to keep the screen small.

All new methods learn their output map without a content-vector skip or auxiliary pretraining. Each outputs one unit 768-dimensional vector: normalize(0.5*existing_non_attribute + 0.5*normalize(new_attribute_aggregate)). Empty attribute sets use zero attribute contribution. This only changes the attribute aggregator. BGE remains frozen.

Train seed42 first: existing pairwise softplus((q.neg-q.pos)/0.05), AdamW, weight decay .01, clip norm 1, batch16, learning rates {0.001,0.0003}, max10 epochs, patience3 completed epochs without strictly better development Recall@100. One hidden size and one block only. Select the trained checkpoint with highest dev query-macro Recall@100; ties favor earlier epoch, then the first listed learning rate. Preserve every epoch log and every candidate's best checkpoint, including failures. No test metrics are computed until all selection and seed decisions are frozen. Full catalog competitors are used on dev. Invariance is checked before any retrieval evaluation, including each dev checkpoint.

Seed gate: a selected S1/S2/S3 seed42 model must strictly beat the archived Set-Attention development Recall@100 and pass invariance. For qualifying methods immediately run seeds43/44 at the seed42-selected learning rate, with the same dev-only early stopping. S4 has no extra-seed gate in this bounded screen. A candidate exceeding Set-Attention (and thus Canonical on this dev split) stops additional learning-rate search for that architecture and triggers immediate seed confirmation; the prespecified S1/S2/S3 and inexpensive S4 comparisons remain, with no added architecture variants.

Invariance: deterministic sample of 128 catalog products plus empty-set, duplicate, padding and UNK unit tests. Rebuild and aggregate all seven actual existing schedules, with atom-order traces and multiset assertions. Report max/mean L2 and absolute cosine differences; abort before retrieval if max L2 >1e-5 or nonfinite. Full test retrieval uses one C0 vector per item, as in prior set controls. Additionally independently regenerate all seven full catalog schedules for selected checkpoints to audit numerical retrieval boundary effects; retain differences. Do not claim bitwise invariance from a vector cache.

Evaluation uses existing FP32 dot products, full stable descending score sort with catalog-index tie handling, exact same pair-first/query-macro metrics. Recall averages seven schedule inclusion indicators per pair, then relevant pairs per query, then queries. VI=Sometimes, Robust=Always, Never=never included. Preserve mean per-query worst schedule; also report minimum macro schedule Recall separately. Reuse archived baseline rank artifacts, never retrain them. Restrict fully-fitting targets using phase4/results/wands_product_features.csv while retaining all competitors (6,797 held-out Exact pairs/239 queries). This is not a causal truncation decomposition. Target-only competitors are each method's own C0 catalog; use the existing target reinsertion routine for dev-selected successful architectures, or the strongest dev model as an explicitly negative diagnostic if none succeeds. Call it Inclusion, not mixed-index Recall.

Uncertainty: 10,000 paired query-bootstrap draws, inherited seed20260963, percentile 95% intervals; all four baseline comparisons plus S2-S1 and S3-S4. Query uncertainty is conditional on trained checkpoints; additional seeds are reported separately, not treated as independent queries. No multiplicity correction or equivalence claim from a CI covering zero.

Record field encoding reuse/legacy timing, training-only time, repeated dev-generation and ranking costs, final catalog generation time, parameters, one-vector storage, unchanged query encoding and online scoring. Keep negative results and answer all six interpretation questions. Select exactly one A/B/C/D recommendation in PHASE6_REPORT.md without changing the paper or launching Phase VII.
