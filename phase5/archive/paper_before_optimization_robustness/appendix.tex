\section{Additional Experimental Detail}

\subsection{Representation audit}
Each primary representation preserves the title and all raw attribute key-value atoms. C0 uses source order, C1 reverses attributes, and C2s1--C2s5 use independent deterministic per-product permutations. The audit checks atom multiplicity, character and token multisets, numeric substrings, and source JSON values. These tests isolate ordering within the supported equivalence definition; they do not assert that all strings are equally fluent.

\subsection{Additional mitigation variants}
\label{app:mitigations}
Using the same development protocol, late mean, late maximum, and late top-3 aggregation all satisfy the numerical invariance tolerance. On held-out WANDS their cNDCG@10 values are 0.8058, 0.8093, and 0.8106; each paired confidence interval establishes a loss relative to 0.8247 Original. On ESCI they achieve 0.7026, 0.7041, and 0.7026, with all intervals including zero. These variants are omitted from the main-paper frontier plot for legibility; their paired intervals appear in the main-paper effectiveness-interval figure.

\subsection{Official ESCI pools}
Official judged pools contain a median of 16 products. MiniLM, BGE, and GTE obtain NDCG@10 of 0.6853, 0.7124, and 0.7168, and micro VI@10 of 7.60\%, 6.65\%, and 11.55\%. At top 20, micro VI is 3.00\%, 2.86\%, and 5.89\%. Query-macro VI@20 is 1.30\%, 1.30\%, and 2.88\%.

\subsection{Scope of the query taxonomy}
Exploratory query classes were assigned by deterministic lexical rules. Because they lack blinded human annotation and agreement measurement, we do not use them to support the main causal claim. Query-level outputs retain the identifiers required for a later annotation study.

\subsection{Result provenance}
All values in the paper map to machine-readable source files in \texttt{RESULT\_PROVENANCE.md}. The audit and output tests can be run with:

  phase3/tests -q
\end{verbatim}
