\paragraph{Operational and valid-output populations.}
The main operational analysis replaces generation errors and length-truncated text with canonical input, while allowing nonempty fact-check failures to expose the raw adapted pipeline. The guarded variant additionally replaces every fact-check failure. Table~\ref{tab:optvalid} requires all seven raw-order outputs and the canonical-input output to pass for the same product; this leaves two ESCI heuristic products and no other support. Empty cells are retained rather than silently dropped. Fact-component, truncation, fully-fitting, transition, and rank-level files accompany the artifact.

\paragraph{Generation variation.}
Table~\ref{tab:optnoise} computes order VI separately inside each stochastic replicate. Its same-input columns instead hold C0 or canonical text fixed and vary only generation. These quantities are deliberately not pooled. Each WANDS cell contains six query--product pairs and each ESCI cell two; the control diagnoses confounding but does not estimate a stable population rate.
