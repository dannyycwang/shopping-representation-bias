# Retrieval-first extension: initial audit (2026-09-07)

Current repository manuscript is the 11-page `paper_www2027/main.pdf`, with the expanded presentation manifest. No `main(2).pdf` attachment is available in this request; the repository source is the working baseline. Preserve it before editing. Unrelated parent-repository application changes are user work and are excluded.

Confirmed issues and scope:

1. **ESCI gains are reversed relative to the benchmark paper.** `phase2/config/phase2.json` uses E=1,C=.1,S=.01,I=0. Reddy et al., Section 3.1, explicitly defines E=1,S=.1,C=.01,I=0; the pinned `ranking/train.py` agrees. Follow-up inspection found the official repository itself has an inconsistent evaluation path: `prepare_trec_eval_files.py` maps S to 2 and C to 3, while the shell assigns 2=.01 and 3=.1. The initial assumption that these evaluation scripts agreed was incorrect. Use the paper's explicit standard definition, preserve both settings and document this upstream inconsistency rather than silently choosing one. Highest-label recall, ranks, and VI are unaffected.
2. Historical VI is the any-in/any-out indicator over seven variants, not a random-update failure probability. Report never-retrieved separately. Common-pool reranker VI is conditional and not directly comparable with all-highest VI.
3. Historical reranker reads the matching C0/C1/C2 variant, max_length=256 with joint tokenizer truncation. Its experiment mixes candidate changes and reranker-input changes. The extension uses one canonical text per product for all first-stage methods.
4. Dense embeddings use normalized vectors, FP16 CUDA weights and FP32 pooling. BGE uses CLS, 512 tokens, empty query prefix; MiniLM uses mean pooling and 256 tokens. BGE v1.5 documentation supports use without instruction but recommends a query instruction for retrieval. Retain the historical empty-prefix condition and label it; do not silently replace it.
5. Historical first-stage reranker top-100 uses argpartition then stable sorting within the selected set; this does not guarantee global stable ordering at exact boundary ties. New rankings use full stable sorting. Quantify legacy differences before changing any legacy pipeline claims.
6. Existing set mean normalizes the attribute mean before interpolating with the non-attribute vector. The old manuscript equation omits that intermediate normalization; correct the equation, not the stored result.
7. WANDS gain 3/1/0 is a declared study convention. Recall excludes queries with zero highest-label judgments (NaN), while cNDCG retains every positive-IDCG query regardless of highest-label availability. Prior join repair must remain intact.
8. WANDS/ESCI historical results have been read. This is a post-hoc extension. A frozen prospective query sample, if available, must be clearly separated from the previously observed external evaluation and must use a common catalog within every comparison.
9. WWW 2027 official research CFP specifies 8 main pages and at most 12 total including references/appendix, anonymous sigconf review. Conference dates are 10–14 May 2027, Dublin. Preserve the expanded reading draft; prepare a compliant new version with no invented DOI.

Runtime amendment: BGE batch size 48 exhausted efficient local GPU memory on long batches; its unfinished encoding attempt was stopped and logged. New encoding uses batch size 16 (MiniLM 64), with identical models, precision, text and token budgets. This is a resource adjustment, not an outcome-driven strategy change. The failed launch computed only the historical Original baseline on the full query set; all new-strategy screening was restricted to the 96 development queries before selection.

Follow-up numerical audit: historical set mean uses its own separately encoded query cache. Its maximum difference from the Original query cache is 0.0006562 (WANDS) / 0.0006135 (ESCI). Reconstructing the old set-mean scores with the old query matrix agrees within 2.39e-7; substituting the shared Original query matrix changes scores by up to 0.0003293 / 0.0002217. This explains small differences between historical repaired mitigation metrics and the new common-query strategy table. Preserve the historical ranks, and use one shared query matrix for all new comparisons. Evidence: `phase4/results/shared_query_cache_audit.csv`. This is a numerical-condition reconciliation, not a new effectiveness claim.
