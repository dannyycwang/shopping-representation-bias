PHASE VI-B — TRAINING-SCALE AND VALUE-PRESERVING INVARIANT REPRESENTATIONS

Important scientific objective
==============================

This is a reinforcement experiment for Phase VI.

Do NOT invent additional architectures.

The purpose is to answer one specific question:

    Did the Phase VI invariant architectures fail because the
    architecture is unsuitable, or because the training regime was
    too small and the new output projections failed to preserve the
    pretrained BGE retrieval geometry?

Phase VI used only 546 supervised triples.

The new Set Transformer / DeepSets architectures introduced substantial
randomly initialized projection/output mappings, whereas the older
Set-Attention preserved the original frozen BGE field value vectors directly.

Phase VI showed:
- Set-Attention Recall@100 = 62.173
- DeepSets Recall@100 = 60.795
- Set Transformer Recall@100 = 55.097
- Original Recall@100 = 63.620
- Canonical Recall@100 = 63.237

All invariant methods achieved approximately zero VI.

Training loss often continued decreasing while development retrieval degraded,
and most selected checkpoints occurred at epoch 1.

Phase VI-B therefore tests:

1. more supervision;
2. stronger negative training;
3. residual/value-preserving initialization;
4. whether structural invariance can approach Original/Canonical retrieval
   effectiveness when training is no longer severely data-limited.

==================================================
3. CORE HYPOTHESES
==================================================

H1 — Training-scale hypothesis
------------------------------

546 triples may be insufficient to train a new invariant aggregation network
into the pretrained BGE retrieval space.

Increasing the number and diversity of supervised query-product comparisons
may improve retrieval without affecting structural invariance.


H2 — Retrieval-space preservation hypothesis
---------------------------------------------

Phase VI required the new models to learn a new 768-dimensional output mapping.

Instead, an invariant model should begin near an existing useful BGE-derived
representation and learn only a corrective residual.

Test:

    v_base(p)

    delta(p) = invariant_network(fields)

    v_final(p) =
        normalize(
            v_base(p) + alpha * delta(p)
        )

where alpha is either learned or initialized small.

This provides an identity/value-preserving path.


H3 — Stronger contrastive supervision hypothesis
-------------------------------------------------

One-positive / one-negative triples may provide too weak a ranking signal.

Test in-batch or multi-negative contrastive learning using the same permitted
training judgments.

6. RESIDUAL / VALUE-PRESERVING ARCHITECTURE
==================================================

This is the most important Phase VI-B modification.

For both DeepSets and Set Transformer, retain the existing invariant attribute
aggregator but change the final representation path.

Define an existing strong invariant/base representation.

Primary base:

    v_base = Set-Attention representation

Alternative diagnostic base:

    v_base = Set-Mean representation

Do NOT use Original flattened serialization as the primary residual base,
because that would reintroduce order sensitivity.

For the learned invariant branch:

    delta_attr = invariant_network(attribute_embeddings)

Map it to 768 dimensions.

Then:

    v_attr =
        normalize(
            v_base_attr + alpha * delta_attr
        )

Preferred alpha initialization:

    alpha = 0.05

or:

    alpha = sigmoid(beta)
    with beta initialized so alpha approximately 0.05

The network must therefore start close to the existing useful invariant
representation rather than from a random retrieval vector.

An even safer alternative is:

    v_attr =
        normalize(
            (1 - alpha) * v_base_attr
            + alpha * v_learned_attr
        )

with alpha initialized near zero.

Choose one primary formulation before inspecting test results.

Document the exact formula.

==================================================

Strong success:

    VI@20 ~= 0

AND

    Recall@100 >= Canonical (63.237%)

    Recall@100 >= Original (63.620%)

AND

    Robust@100 >= Canonical

Promising:

    Recall@100 >= Set-Attention (62.173%)

with development-supported improvement

AND

    exact / numerical invariance retained.

Training-scale evidence:

Even if Canonical is not reached, a clear monotonic improvement from:

    25% -> 50% -> 100%

would justify the statement that Phase VI was supervision-limited.

Failure:

- residual initialization works but additional training does not improve;
- scale curve saturates below Set-Attention;
- more data only overfits;
- zero VI comes with persistent Recall / Never degradation.
