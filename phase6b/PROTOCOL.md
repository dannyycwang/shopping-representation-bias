# Phase VI-B prespecified protocol

Only the existing Phase VI DeepSets (S4) and Set Transformer (S1) branches are studied. Keep all historical Phase VI files and all reused artifacts unchanged; every new output is under phase6b/. The raw WANDS/BGE track, catalog order, cached atom/query/non-attribute embeddings, 72/24/384 query split, seven schedules, FP32 scoring, stable catalog-index ties, query-macro metrics and raw fully-fitting support are unchanged. There is no labeled PI-FT training, no new architecture, no additional blocks, and no circle or Set Transformer + Field-ID experiment. DeepSets retains the field-ID component already present in Phase VI S4. Its original 2,582-entry vocabulary is frozen across regimes and fractions so vocabulary changes cannot explain the scale curve.

Residual formula: b_attr = normalize(sum_i softmax(frozen_SetAttention_s42(h_i))*h_i); delta_attr = unnormalized output of the existing Phase VI invariant branch; alpha = sigmoid(beta), beta initialized to log(.05/.95); v_attr = normalize(b_attr + alpha*delta_attr); v_final = normalize(.5*existing_non_attribute + .5*v_attr). The Set-Attention scorer is frozen. Zero-initialize the branch's final 768-dimensional linear weight and bias. Thus delta is exactly zero at epoch 0 and the model begins at Set-Attention up to floating-point normalization tolerance. All other branch parameters use their original initialization. One shared scalar alpha is learned; its distribution over products is a point mass, while residual magnitudes vary by product. No auxiliary loss or Set-Mean base variant is added.

Audit all training judgments first. T0 exactly reuses the 546 prior triples. T1 uses every Exact query-product pair whose TRAIN query has an explicitly Irrelevant judgment, with one deterministic negative. Preserve T0's original negative for its pairs. Other negatives use deterministic query/positive/negative hash order. T2 uses the identical positives, with up to eight distinct explicitly Irrelevant negatives per pair from that order, including the T1 negative first. Partial and unjudged products never enter the loss. Queries with Exact but no explicit Irrelevant judgments are excluded with a complete list. No cap on eligible positives. Negatives are fixed per example across epochs/seeds to isolate the optimizer seed; repeated products across queries are legal only under that query's own label. Product embeddings may be computed once within a batch and gathered back; no positive from another query is automatically a negative.

Loss: logsumexp([q.pos, q.neg_1,...,q.neg_K]/.05) - q.pos/.05. For K=1 this equals the inherited pairwise softplus loss. Missing slots use an explicit mask, not repeated negatives. Training batch16 query-positive pairs; AdamW lr {1e-4,3e-4}, weight decay .01, max20 epochs, patience4, global gradient clipping at1. Frozen base and BGE excluded from optimizer. Two primary architectures x T0/T1/T2 x two learning rates, seed42. No 1e-3 trial. Strict improvement tolerance1e-12 on dev Recall@100; secondary Robust@100; ties favor earlier epoch then lower LR. Epoch0 is an eligible safety checkpoint: returning the base is recorded as no learned improvement, not a successful training result.

Mandatory initialization guard BEFORE training: two seed42 architectures, independent sampled permutations, full catalog vector generation and comparison to the archived Set-Attention product vectors (max L2 <=1e-5). Report dev and test initialization metrics; test is read only for this prespecified identity/implementation guard, never to select a learning parameter. Require initial dev and test Recall@100 within .05 percentage points of the archived base. Any failure stops training for debugging. Every candidate, including later seeds, also checks zero residual, base cosine and dev metrics at epoch0. Further test evaluation waits for the final selection lock.

Every epoch retains training loss, dev Recall@20/100 and Robust@100, per-step pre-clipping gradient norms, alpha, mean base/residual norms and cosine(final,base). Invariance: reuse the Phase VI sample of 128 products and actual seven schedules, reaggregate the base AND residual each time, assert atom multisets and serializer correspondence, abort before dev retrieval if max L2>1e-5. Unit tests also exercise nonzero learned residuals. Selected models get an independent full-catalog seven-schedule rank audit. Primary tables retain the existing single cached vector deployment convention; tiny floating-point rank changes are separately disclosed.

Scale curves: create nested 25%/50%/100% prefixes of the expanded T2 positive-example list, globally ordered by SHA256(phase6b-scale42:query_id:positive_id), retaining each example's fixed negative list. Run 25%/50% for BOTH architectures to meet the required two-line figure. Use each architecture's full-data T2 seed42-selected LR for all fractions; the 100% run is reused, never retrained for the curve. Fraction runs use seed42, same max20/patience4 and dev selection, with no extra LR grid. Fractions are diagnostics and do not replace the primary full-data/T0 model choice. Interpret more examples as also more optimizer steps per epoch, not an isolated sample-size causal effect.

Choose each architecture's primary winner among its T0/T1/T2 seed42 selected checkpoints using dev Recall@100, Robust, earlier epoch, fewer examples, then lower LR. If that winner matches/exceeds Canonical on development and passes invariance, run seeds43/44 at its selected regime/LR. This trigger is permissive because the frozen Set-Attention base already exceeds Canonical on dev; extra seeds and base-only checkpoints cannot by themselves establish learned gains. No strong claim without gains supported across seeds. No additional architecture variants regardless of outcome.

Target-only gate is stricter: positive trained epoch AND dev Recall@100 strictly above Set-Attention AND invariance passes. Run target-only only for primary architecture winners and their confirmation seeds that individually pass this gate. Competitors are each model's own C0 catalog, using the existing target removal/reinsertion and tie handling. If none pass, do not run a negative target-only diagnostic.

Freeze all selections, learning curves and seed/target gates before evaluating trained checkpoints on the historical 308-query/21,299-Exact-pair test.
